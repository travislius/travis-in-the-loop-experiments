# Agent Skills Explained — what does a skill change? (2026-11-10)

Experiment for the Travis in the Loop video **Agent Skills Explained**. Small and honest: it shows the mechanism, it is not a benchmark.

## Setup
- **Harness:** DeepSeek Harness Python SDK/runtime `0.2.1rc2`, profile `sdk` (standard tool set), approvals off, DSH Seatbelt sandbox `workspace-write`, session-log upload disabled (`patches/`).
- **Model:** `deepseek-v4-flash`, default settings, `max_tokens` 32768.
- **Skill discovery:** the harness's own filesystem skill provider; skills placed in `<workspace>/.agents/skills/`. The model sees a catalog (name + description) and loads a skill with the `skill` tool.
- **Task** (`task/repo/expenses.csv`, generated by a fixed-seed script): 64 rows, 3 date formats, 4 money formats, voided rows, 4 duplicate rows, raw categories that must map to 5 house categories, flag every expense > $500. Same prompt for every run:
  > Please make the October 2026 expense report from expenses.csv in this folder and save it as report.md.
- **Conditions** (all have the same two unrelated skills, `changelog-writer` and `pdf-form-fill`, in the catalog):
  - **A** no expense skill
  - **B** `expense-report` skill, SKILL.md with rules + exact output format (`skills/B`)
  - **C** same skill, SKILL.md tells the agent to run the bundled `scripts/build_report.py` (`skills/C`)
- **Runs:** 8 per condition, interleaved (A,B,C in parallel per round) = 24 scored runs. One pilot run (C) before the matrix is kept in `pilot/` and not scored.
- **Grading:** `check.py` (deterministic). `pass` = numbers correct (total, all 5 category amounts, flag set) AND exact house format. Ground truth in `task/truth.json`.
- Metrics come from each run's own session log (`session-logs/`, local paths redacted).

## Results
| condition | pass | numbers | exact format | grand total right | skill loaded | script used | median wall s | median output tokens | median prompt tokens (input+cached) |
|---|---|---|---|---|---|---|---|---|---|
| A · No skill | 0/8 | 0/8 | 0/8 | 8/8 | 0/8 | 0/8 | 37.75 | 6446 | 113962 |
| B · Skill: instructions only | 8/8 | 8/8 | 8/8 | 8/8 | 8/8 | 0/8 | 23.45 | 3806 | 67300 |
| C · Skill + script | 8/8 | 8/8 | 8/8 | 8/8 | 8/8 | 8/8 | 17.25 | 2072 | 69766 |

Context cost of the installed skill: the catalog message grew by **467 characters** (≈100 tokens) when the expense skill was present. SKILL.md body: 1609 chars (B) / 1251 chars (C). Script: 2347 chars.

Readout
- Without the skill the agent got the grand total right in 8/8 runs but used raw categories, no $500 flags and its own report format → 0/8 pass. Expected: the house rules exist nowhere else.
- With the skill (B or C) the agent loaded it by itself from the description in 16/16 runs and passed 16/16.
- The script (C) mostly cut cost: median 17.3 s vs 23.5 s and ~2.1k vs ~3.8k output tokens.

## Limitations
One synthetic task, one model, one harness, 8 runs per condition. A is not a fair "capability" comparison — it tests what a skill adds when the procedure is otherwise unknown. Token counts are harness-reported; character→token is approximate. API spend for all runs was small (cents).

## Reproduce
```
uv venv -p 3.12 .venv && uv pip install --python .venv/bin/python deepseek-harness-sdk==0.2.1rc2 deepseek-harness-runtime-bin==0.2.1rc2
export DEEPSEEK_API_KEY=...   # never committed
./run.sh A 1      # or ./run_matrix.sh ; then python3 analyze.py
```
`run.sh` reads the key from the macOS keychain; replace that line with your own environment variable. Agents need `python3` ≥ 3.10 on PATH.
